No data collection

This application runs entirely in the browser and does not collect, transmit, or store any personal data. All audio processing is performed locally on the user's device using the Web Audio API; no recordings are uploaded or sent to any server.

Hosting and privacy statements

The static files for this project are served via GitHub Pages. As such, users should refer to GitHub's own privacy policies for information regarding cookies, logs, and other data that may be processed by the hosting platform.
